# Cybersecurity Home Lab
## Project Overview
This project is a hands-on cybersecurity home lab built using Ubuntu Server in a virtual machine. 
The purpose of this lab is to develop practical IT and cybersecurity skills through system administration, Linux security, networking, troubleshooting, monitoring, and security hardening.
## Lab Environment
-Operating System: Ubuntu Server
-CPU: 4 cores
-RAM: 4 GB
-Storage: 32 GB
-Network: Private IPv4 network
-SSH: Enabled
-Firewall: UFW enabled
## Current Configuration
-Ubuntu Server installed
-System packages updated
-Kernel updated
-Network connectivity verified
-DNS resolution verified
-OpenSSH server installed and verified
-UFW firewall enabled
-SSH access allowed through the firewall
## Goals
-Practice Linux system administration
-Learn and apply security hardening techniques
-Configure and troubleshoot network services
-Analyze system and security logs
-Practice incident response concepts
-Build hands-on cybersecurity experience
-Document project for a professional GitHub portfolio
